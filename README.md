# Swordfish - Swordfish - Tab Explorer

A lightweight Chrome extension that organizes browser tabs in an **IDE-style explorer**.

Swordfish turns your open browser tabs into a simple tree structure, grouping tabs by domain so you can navigate and manage them from Chrome's side panel.

## Features

- IDE-style Swordfish - Tab Explorer
- Group tabs by domain
- Expand and collapse tab groups
- Search tabs by name
- Create new tabs
- Close tabs
- Reload tabs
- Reload animation
- Highlight the active tab
- Live updates when tabs are created, closed, or changed
- Website favicon displayed at the domain/group level
- Runs entirely inside Chrome's side panel

## Privacy

Swordfish processes tab information locally in your browser.

It does not collect, store, sell, or transmit your browsing activity or tab information to external servers.

See [PRIVACY.md](PRIVACY.md) for the full privacy policy.

## Permissions

Swordfish uses the following Chrome permissions:

- `tabs` — required to read and manage open browser tabs.
- `sidePanel` — required to display Swordfish in Chrome's side panel.

These permissions are used solely to provide Swordfish's tab organization and management functionality.

## Development

### Run locally

1. Clone or download this repository.
2. Open Chrome and go to:

   `chrome://extensions`

3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the Swordfish project directory.

After making changes, use the reload button on the extension's card in `chrome://extensions`.
