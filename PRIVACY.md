# Swordfish - Tab Explorer Privacy Policy

**Last updated: August 8, 2026**

Swordfish - Tab Explorer is an independent Chrome extension that provides an IDE-style explorer for organizing and managing browser tabs.

## Information Swordfish accesses

Swordfish accesses information about the user's open browser tabs, including:

- Tab titles
- Tab URLs
- Tab favicons
- Tab IDs
- Active tab state
- Tab loading state

This information is required to provide Swordfish's core functionality.

## How this information is used

Tab information is used only to:

- Display open browser tabs
- Group tabs by domain
- Search tabs by title
- Switch between tabs
- Create new tabs
- Close tabs
- Reload tabs
- Display the active tab
- Display website favicons at the domain/group level

## Data storage

Swordfish does not store users' browsing information on external servers.

Tab information is processed locally within the user's browser.

## Data sharing

Swordfish does not sell, rent, or share users' browsing information with third parties.

Swordfish does not transmit tab URLs, tab titles, browsing history, or other tab information to external servers.

## Advertising and sponsorship

Swordfish may display a small sponsorship area within the extension.

Sponsorship content is not personalized, targeted, or selected based on the user's browsing activity or the websites they have open.

The sponsorship area is separate from the tab-management functionality.

Swordfish does not use browsing information to select or personalize sponsorship content.

## Analytics and tracking

Swordfish does not currently use analytics, tracking, fingerprinting, or advertising tracking services.

## Changes to this privacy policy

If Swordfish's data practices change in the future, this privacy policy will be updated to accurately describe those practices.

## Contact

For privacy questions, support, or sponsorship inquiries, please use the developer contact information provided on the Chrome Web Store listing.
