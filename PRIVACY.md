# Swordfish - Tab Explorer Privacy Policy

**Last updated: August 16, 2026**

Swordfish - Tab Explorer is an independent Chrome extension that provides an IDE-style explorer for organizing and managing browser tabs.

Swordfish is designed to process browser tab information locally within the user's browser. Swordfish does not operate a remote server for collecting or storing users' browsing information.

## Information Swordfish accesses

Swordfish accesses information about the user's browser tabs that is necessary to provide its tab-management features, including:

- Tab titles
- Tab URLs
- Tab favicons
- Tab IDs
- Active tab state
- Tab loading state
- Tab group information when importing or working with Chrome tab groups

This information is accessed only to provide Swordfish's tab organization and management functionality.

## How this information is used

Tab information may be used to:

- Display open browser tabs
- Group tabs by domain
- Search tabs by title
- Switch between tabs
- Create new tabs
- Close tabs
- Reload tabs
- Display the active tab
- Display website favicons
- Create and manage custom groups
- Add saved websites to custom groups
- Import existing Chrome tab groups
- Restore and manage saved tab organization
- Display tab-related history within Swordfish

Swordfish does not use browser tab information for purposes unrelated to its tab-management functionality.

## Local storage

Swordfish uses Chrome's extension storage to persist functionality such as:

- Custom groups
- Saved websites
- Expanded or collapsed group state
- User preferences
- Appearance settings
- Other extension settings required for Swordfish to function correctly

This information is stored using Chrome's extension storage and is not transmitted by Swordfish to an external server.

Chrome's extension storage is separate from Swordfish's website or any external service. Swordfish does not maintain a remote database containing users' tab information.

## History

Swordfish may maintain a local history of tab-related information to provide its History feature.

History information is used only within Swordfish to help users find and reopen previously accessed tabs or websites.

Swordfish does not transmit this history to external servers or third parties.

## Custom groups and saved websites

Swordfish allows users to create custom groups and manually save websites within those groups.

Information such as website URLs, titles, and group organization may be stored locally so that these groups can persist between sessions.

This information is used solely to provide the custom-group functionality.

## Data sharing

Swordfish does not sell, rent, or share users' browsing information with third parties.

Swordfish does not transmit tab URLs, tab titles, browsing history, custom groups, saved websites, or other tab-related information to external servers.

Swordfish does not use third-party analytics, tracking, data brokers, or advertising networks to collect browsing information.

## Advertising and sponsorship

Swordfish may display a small sponsorship area within the extension.

The sponsorship area is intended to provide space for potential sponsors or promotional content.

Sponsorship content is not personalized, targeted, or selected based on the user's browsing activity or the websites they have open.

Swordfish does not provide sponsors with users' tab information, browsing history, URLs, titles, or other browsing data.

Swordfish does not use browsing information to select or personalize sponsorship content.

## Analytics and tracking

Swordfish does not currently use analytics, fingerprinting, behavioral tracking, or advertising tracking services.

Swordfish does not collect usage statistics or browsing activity for analytics purposes.

## External services

Swordfish does not require an external account or remote Swordfish server to provide its core functionality.

The extension operates within Chrome and uses Chrome's extension APIs to manage tabs and store extension data locally.

## Data security

Swordfish is designed to minimize the handling of user data by processing tab information locally within the browser and not transmitting it to external servers.

Users should keep Chrome and their installed extensions up to date and only install extensions from trusted sources.

## Changes to this privacy policy

If Swordfish's data practices change in the future, this privacy policy will be updated to accurately describe those practices.

Material changes to how user data is handled will be disclosed as required by applicable Chrome Web Store policies.

## Contact

For privacy questions, support, or sponsorship inquiries, please use the developer contact information provided on the Chrome Web Store listing.

## Chrome Web Store Limited Use

Swordfish's use of information obtained through Chrome APIs is limited to providing and improving its disclosed single purpose: browser tab organization and management.

Swordfish does not sell, transfer, or use user data for purposes unrelated to this functionality, including personalized advertising, creditworthiness determination, or lending purposes.
